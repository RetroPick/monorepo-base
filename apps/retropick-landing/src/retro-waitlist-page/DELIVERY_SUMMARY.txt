║                         API SPECIFICATION                                  ║
╚════════════════════════════════════════════════════════════════════════════╝

ENDPOINT: POST /api/waitlist

Request Body:
  {
    "email": "user@example.com",
    "source": "landing"  // optional
  }

Success Response (200):
  {
    "success": true,
    "message": "Successfully joined waitlist. Check your email!"
  }

Error Responses:
  400 - Invalid email format
    { "error": "Invalid email address" }
  
  409 - Already on waitlist
    { "error": "This email is already on the waitlist" }
  
  500 - Server error
    { "error": "Internal server error" }

╔════════════════════════════════════════════════════════════════════════════╗
║                        DATABASE STRUCTURE                                  ║
╚════════════════════════════════════════════════════════════════════════════╝

TABLE: waitlist_signups

  id              BIGINT NOT NULL PRIMARY KEY (auto-increment)
  email           TEXT NOT NULL UNIQUE (constraint prevents duplicates)
  source          TEXT DEFAULT 'landing'
  created_at      TIMESTAMP WITH TIME ZONE (auto-set on insert)
  updated_at      TIMESTAMP WITH TIME ZONE (auto-update on change)

INDEXES:
  ✅ idx_waitlist_email on (email)
  ✅ idx_waitlist_created_at on (created_at)

POLICIES (RLS):
  ✅ public_read_waitlist - Anyone can read
  ✅ public_insert_waitlist - Anyone can insert
