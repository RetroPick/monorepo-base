## Glossary

- **Template** — Market definition keyed by `templateId` (type, feeds, fees, execution mode).
- **Epoch** — One cycle: open → lock → resolve → claim (often called a **round** in the product).
- **Lock** — Rules and timing are fixed; trading on the outcome typically stops or is restricted per product rules.
- **Checkpoint A / B** — Oracle samples at lock and/or resolve used by resolvers (meanings depend on market type).
- **Manual vs rolling** — **Manual**: keepers drive `openEpoch` / `lockEpoch` / `resolveEpoch`. **Rolling**: pipeline advances rounds on a schedule with fewer discrete actions.
- **Dispatcher + modules** — The live engine uses a **UUPS proxy** with a **dispatcher** boundary; some selectors are **root-owned** (user ops, claims, admin) and others delegate into modules—see the doc above for the current matrix.

## Fees and reserves
