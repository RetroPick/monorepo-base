RetroPick is a **prediction market** platform: you take a side on how a clearly defined question will resolve when the round ends. Outcomes are settled using **automated market data** (Chainlink-style feeds)—not by someone picking a winner by hand.

These docs are for **everyone**: you do not need a deep crypto background to understand how trading and payouts work. Where it helps, we add short **technical notes** for wallet users and developers.

## What you will find here

- **Getting started** — what you need, wallets, and network basics
- **How it works** — lifecycle from open market through lock, settlement, payout, and voids
- **Market types** — all nine RetroPick templates in plain language
- **Oracles & fairness** — why the result is hard to tamper with
- **Technical overview** — glossary and protocol outline (points to the full contract reference in the repo)

## Source material

This site is aligned with the same concepts as the repository’s `.marketTypes.md` (market types) and `package/prediction-v2/currentSmartContract.md` (Solidity-level detail). If anything disagrees with shipped code, **the code wins**.
