---
title: Market types
---

RetroPick ships **nine** market **templates**. Each asks a different question; settlement is always **data-driven** (see **Oracles & fairness**).

| Type | Question in one line |
|------|----------------------|
| **Direction** | Up or down vs a saved snapshot? |
| **Threshold** | At or above a level, or below? |
| **Range close** | Which price **zone** at close? |
| **Velocity** | **How much** did it move (either direction)? |
| **Ladder** | Which **tier** at close, with **weighted** payouts? |
| **Convergence** | Are two assets **closer** or **further apart**? |
| **Composite** | Do **multiple** conditions combine to true? |
| **Corridor** | Did price **stay inside** a band the whole time? |
| **Cascade** | How many **stacked levels** were **broken**? |

Use the pages in this section for examples, void rules, and when each type fits your view.
