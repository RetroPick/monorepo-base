---
title: Range close
---

**Question:** Which **price bucket** will the asset **close in**?

The range is split into **zones**. Only the zone that contains the **final** price wins; **intraday** path does not matter.

## How it settles

At settlement, the closing price falls into exactly one bucket. Everyone on that bucket shares the pool from all other buckets.

## When to use it

Range-bound or **volatility-soft** views—you expect price to **finish in a band**, not necessarily blow out in one direction.
