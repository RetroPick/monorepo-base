# Agent Skills (`.agents/`)

This directory contains **1,918** installable agent skills under `.agents/skills/`. Each skill is a `SKILL.md` file with instructions that guide coding agents on a specific task.

## How to use

- Skills are installed and locked via `skills-lock.json` at the repo root.
- In Cursor or compatible agents, skills are loaded automatically when relevant to your task.
- To inspect a skill, open `.agents/skills/<name>/SKILL.md`.
- Reinstall or update skills with the scripts in `scripts/retropick-skills-install*.sh`.
