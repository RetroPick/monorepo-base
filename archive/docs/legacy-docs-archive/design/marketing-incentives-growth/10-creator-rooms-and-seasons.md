# 10 — Creator Rooms and Seasons

## 1. Why later

Creator rooms need:

```txt
identity
profile stats
leaderboards
referrals
points
```

Build after Phase 2/3.

## 2. Creator room MVP

A room is:

```txt
public group page
tracked invite link
room leaderboard
creator dashboard
```

Example:

```txt
retropick.xyz/rooms/crypto-jakarta
```

## 3. Room page

Show:

```txt
room name
owner tag
member count
weekly leaderboard
top streaks
recent predictions
join button
share room button
```

## 4. Creator dashboard

Show:

```txt
room members
new members
active predictors
D1/D7 retention
first predictions
paid activations later
points generated
room leaderboard
```

## 5. Room incentives

```txt
10 active members: +500
5 D1 retained members: +700
3 paid users later: +1,000
weekly room battle completed: +500
```
