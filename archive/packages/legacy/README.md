# Legacy epoch TypeScript packages (frozen)

Epoch / MarketEngine protocol types, pricing, resolution, and contract registry.

| Package | Purpose |
|---------|---------|
| `@retropick/contracts` | ABI registry JSON |
| `@retropick/market-types` | Template / epoch market shapes |
| `@retropick/pricing` | Pool pricing helpers |
| `@retropick/resolution-core` | Resolution logic |
| `@retropick/equivalence-engine` | Equivalence checks |
| `@retropick/event-core` | Event types |
| `@retropick/gooddollar` | GoodDollar integration |
| `@retropick/chain` | Chain helpers |
| `@retropick/validators` | Validators |

Markets and PRISM must use `packages/polymarket` and `packages/prism`, not these packages.
