# 14 — GoodBuilders Application Positioning

## One-liner

RetroPick gives G$ a simple daily utility loop: users connect, use small G$ amounts in beginner-friendly event markets, learn how resolution works, claim rewards, and grow through fee-funded invite network rewards.

## Description

RetroPick is an event-driven prediction market protocol integrating G$ into simple daily micro-markets for non-crypto and crypto-native users. The first GoodDollar integration focuses on G$ Daily Micro-Markets, Claim-to-Predict onboarding, Learn-to-Predict quests, GoodDollar Identity for verified-human campaigns, EngagementRewards for reward claims, and a public Impact Dashboard showing G$ usage, rewards, verified users, and retention.

## G$ integration status

Planned / in progress.

## Integration type

- G$ token utility.
- GoodDollar Identity / Sybil Resistance.
- EngagementRewards claim flow.
- GoodDollar impact analytics.
- Celo deployment path.

## Why it matters

RetroPick turns G$ from a held/claimed asset into an interactive application currency. Users can use small G$ amounts to participate in simple event markets, learn how on-chain resolution works, and receive rewards for verified learning and real activity.

## Primary build goal

Deploy a Celo/G$ version of RetroPick with beginner-friendly G$ Daily Micro-Markets, Claim-to-Predict onboarding, and EngagementRewards-powered learning/reward claims.

## Growth goal

Convert creator/media outreach and GoodDollar community campaigns into first-time G$ market users, then measure the funnel from connect → G$ balance → first prediction → result viewed → reward claimed → return.

## Milestones

1. Deploy Celo/G$ staging configuration.
2. Ship G$ Daily Micro-Markets page.
3. Integrate GoodDollar Identity status check.
4. Integrate EngagementRewards claim preparation flow.
5. Add FeeRouter and RewardsVault for protocol-funded rewards.
6. Launch GoodDollar Impact Dashboard.
7. Run first sponsored/community campaign.

## Ecosystem impact

RetroPick creates a measurable GoodDollar utility loop around event participation, education, and community growth. The dashboard will report G$ market volume, predictions made, verified users, rewards claimed, returning users, and referral-driven activity.
