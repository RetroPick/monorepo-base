**Question:** Which **tier** will price close in when **tiers have different payout weights**?

Like range-close, but **contrarian** or **rarer** tiers can carry **higher multipliers**.

## How it settles

The winning tier is whichever band contains the **close**. Payouts scale by each tier’s **weight** so harder calls can pay more.

## When to use it

You want **risk/reward** to reflect how difficult your zone is—not every bucket pays the same.
