title: Composite
---

**Question:** Do **multiple** independent conditions end up **true** together under a fixed logic rule?

Up to **four** conditions can each use its own feed/threshold. Rules are typically **And**, **Or**, or **Majority**.

## How it settles

Each condition is evaluated from its oracle reading. The configured logic decides whether **Yes** or **No** wins.

## When to use it

Macro scenarios where **several** things must line up—risk-on packages, joint targets, correlated moves.
